# To-Do List

A clean and responsive To-Do List web application built using **HTML, CSS, and vanilla JavaScript**.

The project was built to practice core JavaScript concepts including DOM manipulation, event handling, objects, arrays, localStorage, and dynamic UI updates.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Persistent tasks using localStorage
- Responsive design for desktop and mobile
- Custom fonts and styled UI
- Interactive hover and editing states

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser localStorage
